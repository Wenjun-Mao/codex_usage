# Support

Use [GitHub Issues](https://github.com/Wenjun-Mao/codex_usage/issues) for Codex
Usage Companion support.

Include the native app and companion versions, operating system, status-bar
state, whether the native app is installed/running, and redacted **Codex Usage**
Output channel text. For Task Transfer, include the operation, both computers'
platforms, transfer-folder provider, and destination-project state.

Never attach raw Codex task JSONLs, `agent.json`, the durable ledger, Task
Transfer files, or unredacted logs publicly.

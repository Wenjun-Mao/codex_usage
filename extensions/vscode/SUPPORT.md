# Support

Use [GitHub Issues](https://github.com/Wenjun-Mao/codex_usage/issues) for Codex
Usage Companion support.

Include the extension version, operating system, status-bar state, whether a
legacy Codex Usage background service is registered, and redacted **Codex
Usage** Output channel text. If Plan Allowance differs from the Codex app,
include the meter's reading label, local observation time, and redacted probe
diagnostic.

Task Transfer was retired in 2.13.0. Existing chats and transfer files remain
untouched. Codex native handoff supports connected hosts with matching saved Git
projects, not offline recovery.

Never attach raw Codex task JSONLs, `agent.json`, the durable ledger, Task
Transfer files, or unredacted logs publicly.
